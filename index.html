AGENT SYSTEM · 2024 — NOW

我主导构建的全链路 AI 新闻生产 Agent。信源经过分级过滤进入流水线，大模型生成正文后经审核与配图，最终多模态分发 —— 下面这条链路完整覆盖了从原始资讯到成品的每一步。

AutoResearch · Agent 自己把自己练强

SELF-EVOLVING LOOP · 无需人工调参

把流水线跑通只是起点。我给这套 Agent 接了 AutoResearch 自进化闭环：它每天产出的稿子会被自动评测与归因，然后由 Agent 自己改写自己的 Prompt 与 Skill，再回到线上做回归验证 —— 评测结论不落在报告里，而是沉淀成可复用的规则。跑得越久，起点越高：效果不是靠我手动调参，而是随迭代自己往上走。
